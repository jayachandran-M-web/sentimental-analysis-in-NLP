# sentimental-analysis-in-NLP

Sentiment Analysis using TF-IDF and Support Vector Machine

Project Overview

This project performs Sentiment Analysis on text data (such as reviews or comments) using Natural Language Processing (NLP) techniques.
The text is converted into numerical form using TF-IDF Vectorization, and sentiment classification is done using a Support Vector Machine (SVM) classifier.

Objectives

Analyze textual data to identify sentiment (Positive / Negative)

Convert text into numerical features using TF-IDF

Train an SVM model for sentiment classification

Evaluate model performance using accuracy and other metrics

Technologies Used

1.Python

2.Pandas

3.NumPy

4.Scikit-learn

5.TF-IDF Vectorizer

6.Support Vector Machine (SVM)
